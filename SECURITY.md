# Security policy

Please do not disclose a suspected vulnerability in a public issue.

- For behavior inherited unchanged from Pages CMS, use the upstream project's
  private security reporting channel when available.
- For FastMigrate downstream patches or deployment-specific behavior, use
  GitHub private vulnerability reporting on this repository.

FastMigrate tracks production dependency advisories on the active release
branch. Dependency updates are tested and reviewed but never deployed
automatically.
